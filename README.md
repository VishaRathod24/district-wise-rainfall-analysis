# District-Wise Rainfall Analysis

## About the Project
This project analyzes district-wise rainfall data across India using Python. It explores rainfall patterns, seasonal variations, annual rainfall distribution, and identifies districts with high and low rainfall.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis
- Data cleaning and exploration
- Statistical analysis (Mean, Median, Mode, Standard Deviation)
- State-wise rainfall comparison
- Seasonal rainfall analysis
- Data visualization
- Outlier detection
- Correlation analysis

## Project Structure
```text
District-Wise-Rainfall-Analysis/

├── README.md

```

## How to Run
1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Open and run `rainfall_analysis.ipynb`.
